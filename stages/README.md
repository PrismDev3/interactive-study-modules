# stages/ — working artifacts for substantial tasks only (layer 4)
- `01-investigation/`: notes for investigations that span sessions, one file per topic.
- `02-planning/`: plans of 15 lines or fewer.
- `03-implementation/`: checkpoints for long changes (files touched, what's left).
- `04-verification/`: test evidence too long for DEVELOPMENT_LOG.md.

Read only the file for the active task. Delete a file once its content is summarised into the owner doc (CONTEXT.md table). Empty folders mean nothing is in flight.
