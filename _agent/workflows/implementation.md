# Implementation
In: the requested outcome. Out: a verified working change, with state and log updated.
1. Small change (2 files or fewer, obvious fix): locate, Edit, bump and check, then verification.md. No plan.
2. Substantial change: write a plan of 15 lines or fewer in `stages/02-planning/<slug>.md` (goal, files, steps, test). Offer alternatives only for a real trade-off.
3. Follow `_agent/conventions/code.md`. Make the smallest correct change, with no new abstractions or deps.
4. Run verification.md. Then add one entry to docs/DEVELOPMENT_LOG.md, update the docs/BACKLOG.md status and PROJECT_STATE.md "Now".
